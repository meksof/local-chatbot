# Web Search Feature

The web search feature allows the chatbot to make a web search and fetch relevant pages from the web.

## What problem does it solve?

The web search feature addresses the limitation of the chatbot's knowledge base by allowing it to access real-time information from the internet. This enables the chatbot to provide more accurate and up-to-date responses to user queries that require current information.

## What is the expected behavior?

The user message input will have an extra toggle button to enable or disable the web search feature. When enabled, the user can type a query and the chatbot will perform a web search and return relevant results.

## User Flow & UX

1. The user types a query in the message input field.
2. The user toggles the web search feature on.
3. The chatbot performs a web search using the query and fetches relevant pages from the web
4. The chatbot displays the search results in the chat interface, along with a summary of the information retrieved from the web pages.
